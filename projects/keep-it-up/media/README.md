# Keep It Up! · Media

**Template folder — media to be added during the project review.**

Use this folder for screenshots and short gameplay GIFs. Larger videos can be linked from the case study.

## Suggested captures

- A short overview of the core gameplay loop.
- A focused clip for each featured system.
- A screenshot that gives the viewer useful game context.

Suggested filenames: `gameplay.gif`, `featured-system.gif`, `gameplay.png`.

## Embedding media in the case study

After uploading the actual file, add a relative image link to the parent README:

```markdown
![Gameplay overview](media/gameplay.gif)
```

Add a brief caption stating what the viewer should notice and which behavior you programmed.
