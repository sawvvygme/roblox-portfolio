## Adding a system

Copy the [system template](../templates/system.md) into `systems/<system-name>/README.md`, then add `code/` and `media/` folders as needed.

Each completed entry should explain the problem, architecture, client / server boundaries, selected code and a short demonstration. Add it to this index once its details are confirmed.
