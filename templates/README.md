# Portfolio Templates

Use these to prepare each project or programming system consistently.

| Template | Use for |
| --- | --- |
| [Project case study](project.md) | A game you worked on, your role and the systems you built |
| [Short project showcase](short-project.md) | A brief role and contribution summary for a game |
| [Programming system](system.md) | A standalone or reusable system with its architecture and code |

## Workflow

1. Copy the appropriate template into `projects/<project-name>/README.md` or `systems/<system-name>/README.md`.
2. Replace bracketed prompts with confirmed details. Remove sections that do not apply.
3. Add `media/` and `code/` folders when there are screenshots, GIFs or selected Luau samples to include.
4. Add relative links to real files and verified external links.
5. Add the entry to the projects or systems index and feature it on the main README when ready.

Until an entry is finished, keep its template status visible. Add only your own confirmed contributions, and credit collaborators where relevant.

For smaller contributions, add a linked game title and one sentence about your work to the [experience credits page](../projects/credits.md). Detailed case studies are reserved for selected work.
